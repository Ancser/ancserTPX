# 1.0.9 刪除清單 — TREND / ML

依「驗證後再刪」原則，先做依賴盤點。分成三類：**可安全刪除**、**不可刪除（名字像但其實共用）**、**需你裁決**。

---

## 🔴 不可刪除 — 名字像 TREND，實際是共用基礎建設

這三項若照字面刪除，會直接弄壞你要保留的 DAY ZONE 與 FACTOR。

### 1. 圖表的 VAH / VAL / POC 繪製 — **這是 DAY ZONE 的核心，不是 TREND 的**

你的指示是「chart 畫 VAH/VAL 區間一併刪除」，但實際查證結果相反：

- `backend/strategy/fade.py:121` 直接讀 `poc, vah, val` 算進出場
- `fade.py:128` `sl = val - SL_TICKS * TICK_SIZE`（結構性停損掛在 VAL 下方）
- `fade.py:129` `tp = val + TP_FRAC * (poc - val)`（TP 取 VAL→POC 的比例）
- `fade.py:134,144` 進場條件是 `candle.low <= val < close < poc` / `val < close < vah`
- **OR15 的進場是「前日 VA 幅 × 0.2」** —— 就是那個你要保留、且唯一同時滿足月入 $2k / maxDD<$1k / PF>2 / MC / WF 的策略

刪掉 VA 線 = 讓唯一達標的策略在圖上變成瞎子。**建議保留。**

（前端對應：`ancserTPX.js:3939` 畫每個 TF 的 VAH/VAL/POC 線、`:4007` 畫單一 zone 的線、`:29` `vahLine`。）

### 2. `StrategyType.TREND_FOLLOW`（`backend/db/models.py:40`，值 = `"trend"`）

這是**所有策略共用**的訊號標籤，不是 TREND 專屬：

| 檔案 | 行 |
|---|---|
| `strategy/factor.py` | 878 |
| `strategy/fade.py` | 158, 345 |
| `strategy/pmo.py` | 361 |
| `strategy/sigma.py` | 348 |

| `live/confluence_live.py` | 238 |
| `live/engine.py` | 397, 2149, 2163 |
| `backtest/metrics.py` | 83 |

刪除 → 每個策略的 `TradeSignal` 都建不出來。**這是命名問題，不是死代碼。** 若要清理，正確做法是改名為 `StrategyType.DEFAULT`，屬於獨立重構。

### 3. `tr_*` 參數命名空間

`sweep.py` 內 77 處。DAY ZONE 的掃描設 `p.tr_sl_ticks`、`p.tr_allowed_sessions`、`p.tr_exit_mode`；FACTOR 也用同一組。OR15 的參數就是 `tr_sl_ticks: 50 / tr_tp_ticks: 200 / tr_allowed_sessions: [...]`。

**這是共用的風控/時段參數，前綴 `tr_` 只是歷史遺留。** 刪除會破壞所有 preset。
