# 1.0.9 策略研究結論 — 公開策略掃描與跨商品驗證

## TL;DR

測了 8 個公開策略族、約 1,860 個變體，**沒有任何一個通過跨商品驗證**。
現役的 OR15 與 BEST 是唯二通過的。研究的淨產出是**一個新的驗證關卡**，
而不是一個新策略。

---

## 新增的關鍵驗證：跨商品交叉驗證

所有策略都在同一個 2.5 個月視窗上被選出，時間上沒有樣本外可用。但
MNQ 與 MES 追蹤不同指數（NQ / ES），相關約 0.9 卻不完全同步 ——
**在一邊選出的參數搬到另一邊，是目前唯一近似樣本外的檢定**。

真實的結構性邊際應至少部分轉移。一搬過去就變負 = 對該商品特定路徑的曲線擬合。

## RSI2 的完整推翻過程（值得記錄的方法論）

1. **初掃**（212 變體 × 2 商品）：RSI2 是唯一在 MNQ 與 MES 上「各自」通過
   全部五道關卡的 → 看起來是跨商品成立。

2. **密網格**（720 變體 × 2 商品）：
   - MNQ：**720 個只有 1 個通過**，且每個維度恰好只有一個值能過
     （len=2、lo=2.0、5m、all、SL1.5、RR3）→ 尖峰，不是高原。
   - MES：RSI 參數本身（len / 門檻 / rr）是平的，但 tf / side / SL 是懸崖
     （7/7 通過者都是 15m、6/7 是 long_only、7/7 是 SL2.5）。

3. **方向偏好矛盾**：MNQ 偏好 short_only（中位邊際 +39.1t，long_only −40.7t）；
   MES 偏好 long_only（+5.8t，short_only −13.6t）。**兩個同期同向下跌的
   相關商品給出相反的方向偏好** → regime 產物。

4. **交叉驗證（決定性）**：
   ```
   MNQ 冠軍 → MES：PF 0.745  ❌
   MES 冠軍 → MNQ：PF 0.853  ❌
   ```
   完美對角線，兩個交叉方向都虧 → **推翻**。

「在兩個商品上都通過」與「用同一組參數在兩個商品上都通過」是完全不同的
主張。前者只是兩次獨立的曲線擬合。

## 對 BETTER preset 的修正

BETTER（SIG 門檻 −0.09）在 MNQ 上各項指標都優於 BEST，但**跨商品驗證不過**：

| | MNQ 邊際 | MES 邊際 |
|---|---|---|
| BEST | 455.0t | **55.2t** ✅ |
| BETTER | 440.0t | **10.6t** ❌ |

放鬆門檻改善了 MNQ 的表現，卻**破壞了 MES 的轉移能力**。MES 樣本只有 7–8 筆，
證據很弱，但這是目前唯一的樣本外訊號，而它指向不利於 BETTER。

**建議：BETTER 暫不上線，保留 BEST。** 等 MES 樣本累積到可判定再重測。

## 建議把驗證關卡改成六道

現行五道（G0 訊號 → G1 獲利 → G2 滑價 → G3 走查 → G4 蒙地卡羅）全部是
**同一份資料的內部檢定**，擋不住曲線擬合。新增：

**G5 跨商品**：同一組參數在另一個商品上，每筆邊際仍 > 14t。

實測顯示 G5 是最嚴的一關 —— 通過 G0–G4 的 8 個研究策略，**全數死在 G5**。
