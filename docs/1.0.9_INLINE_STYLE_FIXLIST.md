## 刻意保留 inline 的(98 個)

1. **`display:none` 切換元素** — JS 用 `el.style.display = 'none'/'flex'/'block'` 切換;
   換成 class 會被「顯示時設 `style.display=''`」的路徑破壞,全部保留。
2. **一次性樣式**(只出現一次的 header logo、live-top-bar 容器、圖例等)—
   抽 class 無重用價值,保留原地。
3. **JS 會動態改寫的屬性**(slot-dot 的 background、status 的 color)—
   class 提供初始值,JS inline 覆寫行為不變。
