# 1.0.9 Rolling Sigma + Random Account Report

## 修正

上一版 `opening_sigma_fade_study.py` 把 15m/30m 當作固定 opening distribution。

本輪修正為：

- 15m/30m 是 rolling lookback window。
- 每根 candle 都用前 15m 或 30m 重新計算 center/sigma。
- 進場用當下最新 sigma band。
- 這才符合「15m 作為計算以後標準差」的意思。

## 實盤風險判斷

rolling sigma 的回測結果很強，但最大的風險不是方向，而是 fill。

原因：

- 高分版本有 5000 到 9000 筆交易。
- 大量 limit/rejection 訊號在 1m OHLC 裡只知道 touched，不知道實際排隊是否成交。
- 1m candle 無法知道 touch level 後是否先反彈、是否排隊 missed、是否被 spread/queue 卡住。
- ALL session 包含低流動性時段，fill 樂觀偏差會更嚴重。

因此不能直接把 Sigma #3 接 live。

最低可接受下一步：

1. 用 30s data 重跑 Sigma #1/#2/#3。
2. 對最佳版本做逐筆 shadow replay。
3. 記錄每個 limit：是否 touch、是否可成交、touch 後 MFE/MAE、missed by queue。
4. 實盤若做，只能先 1 MNQ shadow 或 sim，不進 Topstep 真帳。

## 隨機帳號分佈測試

規則：

- 每天隨機 long/short 1 MNQ。
- 目標 net 約 +1000 / -1000。
- 達 +3000 視為通過考試。
- 達 +4000 視為可出金目標。
- 若 trailing maxDD 達 2000 視為失敗。
- 每種 entry style 跑 100000 條路徑。

結果：

```text
topstep_open:
pass3k   = 23.23%
payout4k = 15.12%
failDD   = 72.02%
unresolved = 12.86%
median days to pass = 11
median days to payout = 14

rth_open:
pass3k   = 21.43%
payout4k = 12.91%
failDD   = 64.52%
unresolved = 22.57%
median days to pass = 16
median days to payout = 21

random_bar:
pass3k   = 20.80%
payout4k = 12.64%
failDD   = 65.31%
unresolved = 22.05%
median days to pass = 16
median days to payout = 21
```

判斷：

- 隨機方向也有約 13% 到 15% 的機率碰到 +4000，這是 gambler's ruin 結構，不是 edge。
- pass3k 約 21% 到 23%，所以短期通過考試本身不能證明策略有效。
- 一個策略要有意義，必須顯著高於這個 random baseline，並且 failDD 大幅低於 65% 到 72%。

## 總結

Rolling sigma corrected version 值得繼續研究；固定 opening sigma 不是正確版本。

最合理的下一步不是直接 live，而是：

- 先用 Codex Sigma #1/#2 做 30s/tick audit。
- 若 30s 後仍然 PNL > 6k、maxDD < 1k、total loss 保持低，才放入 shadow replay。
- 隨機帳號結果作為底線：任何策略如果只是 20% pass / 13% payout 附近，沒有意義。
