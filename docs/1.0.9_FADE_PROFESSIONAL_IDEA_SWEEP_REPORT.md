## Source Concepts

This sweep translated public professional-style concepts into testable rules:

- Volume Profile / Auction Market Theory: value-area rotation, responsive buying/selling near VAH/VAL.

- Exhaustion filters: RSI/KDJ, rolling z-score, volume spike plus wick rejection.
